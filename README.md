# Grovik website

Local Astro project for the Grovik LLC corporate website.

The production site at https://www.grovik.co is a separate deployment. Do not deploy this project until a later phase is approved.

## Scripts

- `npm run dev` — local development
- `npm run check` — TypeScript and Astro validation
- `npm run build` — static production build
- `npm run preview` — serve the production build locally
- `npm run validate` — run checks, then build
